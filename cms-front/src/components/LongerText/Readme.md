# 超长文本显示优化组件

## 组件说明

该组件用于放置可能有大量内容的文本，如果文本超过限制则省略超出内容，将具体内容显示在PopOver中。

## 参数说明
|  字段  |  说明  | 默认值 | 是否必传  |
| ---  |  --- | --- | --- |
|  content  |  放置于组件中的内容，可为纯文本也可为DOM元素 | -  | 否
|  textWidth  | 文本最大宽度 | 250px  | 否
|  popoverWidth | 气泡卡片宽度  |  400px  | 否
|  lineHeight  |  文本行高  |  30px  | 否
|  lineCount  |  最大限制显示行数  |  2  | 否
|
