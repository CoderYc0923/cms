# shopchup独立站项目
## Vue 3 + Vite 

- 使用 setup 语法糖
- 开发前请阅读.eslinttrc.cjs，按照其中的风格编程

> 注意事项 ❗
> 1. 组件名首字母大写驼峰命名
> 2. 自定义组件使用时，直接使用组件名不要转为小写字母加短横线
> 3. 属性名首字母小写驼峰命名
> 4. 使用less
> 5. 使用dayjs


快速开始
```bash
npm install
npm run dev
```

## IDE设置 

- [VS Code](https://code.visualstudio.com/) + [Volar](https://marketplace.visualstudio.com/items?itemName=Vue.volar) (and disable Vetur) + [TypeScript Vue Plugin (Volar)](https://marketplace.visualstudio.com/items?itemName=Vue.vscode-typescript-vue-plugin).


## 目录结构

- `src` - 项目源码
  - `assets` - 静态资源
  - `components` - 组件
  - `config` - 布局、路由配置
  - `consts` - 常量
  - `hooks` - 自定义hooks
  - `layouts` - 布局
  - `router` - 路由
  - `service` - 请求函数
  - `stores` - pinia store
  - `utils` - 工具函数
  - `views` - 页面
